client-server application

Task 1:
Create a simple client-server application where the client asks the server for the current time, you can use Python with its built-in 'socket' module for network communication, and the 'datetime' module for time.

Task 2:
Modify the server to be multi-threaded so that it can handle multiple client requests for the time simultaneously.

Task 3:
Modify the codes so that the server will close the connection only when the client sends a command. (The command should be your index number. eg: ITBIN-2211-xxxx)
